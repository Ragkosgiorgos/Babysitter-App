README 
-Main Rantevou Page:Εμφανίζει όλα τα ραντεβού του χρήστη(babysitter) τα οποία έχουν κλείσει κηδεμόνες.
Αυτό γίνεται ελέγχοντας αν το id_p (το user id του κηδεμόνα που θα παραστεί στο ραντεβού) είναι κενό.Αν δεν
είναι τότε το ραντεβού είναι κλεισμένο και εμφανίζεται.Δίνεται η δυνατότητα να προβληθούν περαιτέρω 
πληροφορίες για το κάθε κλεισμένο ραντεβού και η δυνατότητα ανακατεύθυνσης στην σελίδα των διαθέσιμων
(μη κλεισμένων) ραντεβού.

-Available Rantevou Page:Εμφανίζει όλα τα ραντεβού των οποίων το id_p είναι μια κενή συμβολοσειρά το οποίο 
σημαίνει,ότι δεν το έχει κλείσει κάποιος κηδεμόνας.Τα διαθέσιμα ραντεβού μπορούν να διαγραφούν αφού δεν έχει
γίνει κάποια αίτηση ενδιαφέροντος με βάση αυτά.Μπορεί να γίνει επεξεργασία σε αυτά όπως αλλαγή ημερομηνίας/ώρας
ή και τρόπου συνάντησης.

-Add Rantevou Page:Δημιουργεί ένα νέο διαθέσιμο ραντεβού,χώρις να αφήνει τον χρήστη(babysitter) είτε να παραλείψει
κάποιο πεδίο είτε να μην το συμπληρώσει σωστά.

-Edit Rantevou Page:Δίνει την δυνατότητα στον χρήστη να επεργασθεί τις διάφορες πληροφορίες του κάθε διαθέσιμου 
ραντεβού.Δεν επεξεργάζεται κλεισμένα ραντεβού.

-Proepiskopisi (Available) Rantevou Pages:Προβάλλονται οι σημαντικές ,για τον χρήστη, πληροφορίες του ραντεβού όπως
ονοματεπώνυμο κηδεμόνα,αν το ραντεβού είναι κλεισμένο , ημερομηνία και ώρα , καθώς και τον τρόπο της συνάντησης.

-Main Aitiseis Endiafrontos Page:Με βάση το id του χρήστη βρίσκει τις αιτήσεις ενδιαφέροντος που του αντιστοιχούν και εμφανίζονται 
μερικές βασικές πληροφορίες της,δηλαδή το ονοματεπώνυμο του babysitter και το status της.Έαν κάποια έχει αποθηκευτεί προσωρινά μπορεί
ο χρήστης να την διαγράψει,αφού το ραντεβού δεν έχει κλείστει ακόμα, μπορεί απλά να δει επιπλέον πληροφορίες γιαυτήν , ή και να την 
επεξεργασθεί.

-Edit Aitiseis Endiafrontos Page:Προσδιορίζει αν δημιουργούμε μια καινούργια ή αν επεξεργαζόμαστε μια υπάρχουσα μέσω τις παραμέτρου id.
Αν η ανακατεύθυνση έγινε από αγγελία babysitter τότε το id είναι άδειο που σημαίνει ότι δημιουργούμε καινούργια αίτηση,αλλιώς η 
ανακατεύθυνση έγινε από την αρχική σελίδα των αιτήσεων του χρήστη,άρα επεξεργαζόμαστε μια υπάρχουσα αίτηση.Μέσω της παραμέτρου 
b_id(id του babysitter) παίρνουμε όλα τα δεδομένα για τα ραντεβού του babysitter.Δίνεται στον κηδεμόνα η επιλογή ραντεβού ανάμεσα στα
διαθέσιμα ραντεβού για τον τρόπο συνάντησης που έχει επιλέξει.Ακόμη του δίνεται η δυνατότητα να αλλάξει κάποιο από τα προσωπικά του 
στοιχεία ή τα στοιχεια του παιδιού του,μέσω της επεξεργασίας του προφίλ του,έτσι ώστε να χρησιμοποιηθούν στην αίτηση.Η αποθήκευση είτε
προσωρινή είτε οριστική γίνεται μόνο και μόνο όταν έχουν συμπληρώθει σωστά όλα τα πεδία.Κατά την οριστική υποβολή το πεδίου id_p του 
αντίστοιχου ραντεβού παίρνει την τιμή του user id του κηδεμόνα για να υποδειχθεί ότι το ραντεβού έχει κλειστεί απο αυτόν.Στην προσωρινή
αποθήκευση το παραπάνω,δεν γίνεται αφού το ραντεβού δεν έχει κλείσει,άρα υπάρχει η πιθανότητα να κλειστεί από κάποιον άλλο.

-Preview Aitiseis Endiafrontos Page:Η αρχική σελίδα αιτήσεων στέλνει ως παραμέτρο το id της αίτησης και έτσι εμφανίζει και τις προσωπικές
πληροφορίες του χρήστη που χρησιμοποίηθηκαν στην αίτηση καθώς και τις λεπτομέρειες της συνάντησης.
